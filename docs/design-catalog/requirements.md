# 需求与参与者

## 目标

在固定时间自动预约杭电图书馆座位，并在预约开始前后自动处理签到、暂离、续座、签退和取消，减少人工操作。

## 参与者

| 参与者 | 动作 |
|---|---|
| 学生 | 使用桌面端、Web 端或移动端配置方案、查看座位、创建预约、管理预约、启用自动签到、更新应用 |
| 系统调度器 | 每天 20:00 调用后台抢座 |
| 自动签到任务 | 在签到窗口内调用签到 |
| 慧图图书馆平台 | 提供登录、房间、座位、预约、签到等 HTTP API |
| 杭电 SSO | 提供统一身份认证 |
| 微信 Webhook | 接收成功/失败通知 |
| GitHub Releases | 提供新版本与安装包 |

## 关键约束

- 预约目标日固定为后天。
- 系统任务固定每天 20:00。
- 自动签到必须同意风险协议，协议版本变化后需要重新同意。
- 抢座、签到、调度管理都要求有效登录态。
- 预约写操作成功后必须从预约列表复核最终状态。
- 远端结构漂移时按 fail-closed 处理，不把未知错误当成功。

## 成功标准

- 定时任务能自动预约到配置座位。
- 主座位不可用时能按顺序尝试备用座位。
- 已进入签到窗口的预约能自动签到。
- 预约状态和可用操作在 UI 中与远端一致。
- 所有关键动作有审计日志，失败能通知用户。

## 非目标

- 不处理图书借阅、扫码入馆、定位签到等未接入的写操作。
- 不做多用户会话隔离，当前 Web 模式为单租户。
- 不对账号封禁等后果承担保证。
